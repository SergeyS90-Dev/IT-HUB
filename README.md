Фрунзенская набережная — Sminex — ИНТЕКО

Адаптивный сайт жилого комплекса, разработанный в рамках учебного проекта с применением методологии БЭМ.

О проекте

Основная цель проекта — создание собственного сайта с использованием методологии БЭМ для организации HTML-разметки и CSS-стилей.

В проекте реализованы несколько информационных секций, адаптивная компоновка элементов и интерактивные компоненты интерфейса.

Основные особенности

БЭМ — организация классов и стилей по методологии «Блок — Элемент — Модификатор».

Адаптивная вёрстка — поддержка экранов различной ширины, от 360 до 3000 пикселей.

SCSS (Sass) — использование вложенности и возможностей препроцессора для организации стилей.

JavaScript — реализация интерактивных элементов сайта.

Семантическая HTML-разметка — использование HTML5 и атрибутов доступности для элементов интерфейса.

Анимации — визуальные эффекты при наведении и взаимодействии с элементами.

Оптимизация ресурсов — использование оптимизированных изображений, минифицированных стилей и SVG-графики.

Интерактивность

Бургер-меню для навигации.

Модальное окно с формой обратной связи.

Интерактивные элементы и анимации интерфейса.

Слайдер в секции архитектуры на мобильных разрешениях.
